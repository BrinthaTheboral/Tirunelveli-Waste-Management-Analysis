# Tirunelveli-Waste-Management-Analysis
Analyzed 21 moths of waste data using Python, statistical tests, and visualizations to identify ₹39 Cr. recyclable loss and purpose data-driven interventions.
## Data Information

Original data source: Tirunelveli Municipal Corporation

**Data Structure:**
- Period: May 28, 2024 to January 31, 2026
- Total days: 554
- Locations: Thachanallur, Town, Palayankottai, Melapalayam
- Categories: Bio Waste, Nonbio Waste, Mud from drainage

 
 **Note:** Due to confidentiality and privacy agreements with the municipality, the original raw data is **not included** in this repository.
